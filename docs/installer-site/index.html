Before you settle in

Which file should I download?

Choose NightWatch-Setup-<version>.exe. The .blockmap and latest.yml files are for the app’s updater; the source-code archives are not Windows installers.

What if Windows shows a publisher warning?

Current NightWatch builds are unsigned, so Windows may show an unknown-publisher warning. Verify that your download came from BlastPowa/NightWatch on GitHub before deciding whether to run it.

Can I use this on Mac, Linux, or a phone?

This page provides the Windows desktop installer. It does not offer a Mac, Linux, or mobile package. Check the project on GitHub for other ways to use NightWatch.

How do I get updates?

The desktop app checks GitHub Releases for updates. You can also return here for the current installer and its release notes.
